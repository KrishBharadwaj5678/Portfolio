## <img src="https://github.com/KrishBharadwaj5678/Portfolio/raw/main/src/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонируйте репозиторий:

```bash
git clone https://github.com/KrishBharadwaj5678/Portfolio.git
````

### 2️⃣ Перейдите в папку проекта:

```bash
cd Portfolio
```

### 3️⃣ Установите зависимости:

```bash
npm install
```

### 4️⃣ Запустите сервер разработки:

```bash
npm run dev
```

### 5️⃣ Откройте приложение в браузере.
