## <img src="https://github.com/KrishBharadwaj5678/Portfolio/raw/main/src/assets/readme/features.gif" width="35"/> Recursos

| Seção | Descrição |
| ------------------------ | -------------------------------------------------------------------------- |
| 🏠 **Início** | Uma introdução acolhedora com uma frase pessoal e navegação. |
| 👨‍💻 **Sobre Mim** | Apresenta minha experiência, habilidades e paixão pelo desenvolvimento. |
| 🧰 **Serviços** | Visão geral dos serviços que ofereço. |
| 🏅 **Certificações** | Exibe minhas conquistas e certificações obtidas. |
| 💼 **Meus Trabalhos** | Galeria dos meus melhores projetos com descrições e links. |
| 📞 **Contato** | Formulário de contato e opções para entrar em contato por e-mail. |
| 📱 **Responsivo** | Layout totalmente otimizado para todos os tamanhos de tela. |

