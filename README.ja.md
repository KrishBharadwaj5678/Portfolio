## <img src="https://github.com/KrishBharadwaj5678/Portfolio/raw/main/src/assets/readme/gettingStarted.gif" width="35"/> 始め方

### 1️⃣ リポジトリをクローンします：

```bash
git clone https://github.com/KrishBharadwaj5678/Portfolio.git
````

### 2️⃣ プロジェクトフォルダへ移動します：

```bash
cd Portfolio
```

### 3️⃣ 依存関係をインストールします：

```bash
npm install
```

### 4️⃣ 開発サーバーを起動します：

```bash
npm run dev
```

### 5️⃣ ブラウザでアプリケーションを開きます。
